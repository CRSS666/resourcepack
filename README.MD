# CRSS Resource Pack

This is the required resource pack for playing in the [main CRSS server](https://wiki.crss.cc/w/CRSS_(Server)), adding textures and models for our custom items.  
It also has a panorama that will get updated every once in a while; the first version is the Main Studio of [Quartz News Network](https://qnn.crssi.cc).  

You can read more about CRSS in [The CRSS Wiki](https://wiki.crss.cc/)
